# WUA Maintenance Reporting System

## Project Description
The WUA Maintenance Reporting System is a proposed system for reporting and tracking maintenance issues at Women's University in Africa (WUA).

## Problem
Students and staff may experience difficulties when reporting maintenance problems like broken taps, lights, toilets, and electrical faults. Currently reports are done manually and get lost.

## Proposed Solution
A web-based system where students can report issues, upload photos, track status, and maintenance staff can receive, assign, and update reports.
