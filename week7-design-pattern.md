## 5. Practical Implementation

I implemented the Observer Pattern using Python. The program contains two classes: MaintenanceSystem and MaintenanceStaff. The MaintenanceSystem submits maintenance reports and notifies registered observers. MaintenanceStaff receives the notification when a report is submitted.

I tested the program using the example of a leaking tap in the hostel. The program displayed the message confirming that the report was submitted and another message confirming that maintenance staff were notified. This showed that the Observer Pattern was working correctly.

## 6. Reflection

Through this practical exercise, I learned how to implement the Observer Pattern using Python. I understood how one component can notify another component when an event occurs. I also learned that separating responsibilities makes a program easier to maintain and extend. In the WUA Student Maintenance Reporting System, this pattern could help maintenance staff receive notifications when students submit new reports.
